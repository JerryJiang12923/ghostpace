# 卷灵 GhostPace

> 和一只"幽灵"赛跑着把卷子做完。

每张卷子按题目难度预估一份配速表，幽灵按它跑——会卡壳、会回改、会停顿，像考场里坐在你旁边的那个水平相当的对手。你做题，它做题，余光一瞥就知道自己领先还是落后。

## 特性

- **幽灵引擎**：由种子确定性生成整条配速时间线（OU 游走 + 对数正态噪声 + 卡壳/回改/停顿事件），总时长锁定在预估 ±3%，可用种子完整复盘
- **竞速界面**：横屏双车道进度图，余光模式（幽灵位置随机一瞥），倒数起跑
- **真实计时**：逐题计时、跳题补做、暂停自动扣时、卡壳提醒
- **赛后**：逐题对照、分享图导出、速度校准——幽灵越赛越懂你
- **纯本地**：单页零依赖，数据全在自己设备上

## 快速开始

```sh
git clone https://github.com/JerryJiang12923/ghostpace.git
cd ghostpace
python3 bridge/build_papers_js.py   # data/papers/*.json → app/papers.js
python3 bridge/bridge.py            # 本地桥：比赛数据落盘到 data/sessions/
```

浏览器打开 `app/index.html`，开卷即赛。

## 建卷

工具本身不含卷子。一张卷 = 一份逐题预估的 JSON（题型、难度、预估秒数、知识点），放进 `data/papers/` 再跑 `build_papers_js.py` 就会出现在卷库里。两种造法：

- **AI 估时**：把卷子照片发给 AI agent，让它逐题预估生成 JSON——这是设计的主路径，规程见 [docs/维护手册.md](docs/维护手册.md)
- **手写**：照 `docs/` 里的格式自己写

预估越准，幽灵越像个真对手；不准也没关系，赛后校准会替你修。

## 数据

本仓库只有代码。卷子、比赛记录、校准系数都在本地 `data/`（已被 .gitignore 排除）。把 `data/` 做成独立 git 仓，桥每次落盘会自动提交。

## 结构

`app/` 前端 · `bridge/` 本地桥与生成器 · `docs/` 设计与维护文档 · `design/` 界面稿

## 设计取舍

- **简洁第一**：单页、零依赖、打开就用
- **幽灵没人格**：不说话不催你，只有一条有机的配速曲线
- **数据在本地**：这是一台测量仪器，不是一个平台
